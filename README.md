# Personal research website

This is your Quarto website source. It is designed to publish freely through GitHub Pages once you are ready.

## Before publishing

1. Replace every instance of `Your Name`, the placeholder bio, email address, and links.
2. Replace `images/profile-placeholder.svg` with a square photo of yourself. Update the `image:` line near the top of `index.qmd` to match its filename.
3. Place your CV at `files/cv.pdf`.
4. Add a new short post by copying one of the files in `posts/`, changing its title, date, description, and text.

## Preview locally

Install Quarto from https://quarto.org/docs/get-started/ and then open this folder in RStudio or Positron. Use **Render** or run `quarto preview` from a terminal.

## Publish for free

Create a public GitHub repository called `YOUR-GITHUB-USERNAME.github.io`, upload these files, then publish with `quarto publish gh-pages`. The first time, Quarto will guide you through connecting to GitHub. Your site will be available at `https://YOUR-GITHUB-USERNAME.github.io`.

See Quarto's publishing guide: https://quarto.org/docs/publishing/github-pages.html
